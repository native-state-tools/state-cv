Local-first On this device

About and privacy

State CV is a local-first application: your CV content stays on your device. The app may download its own static files and updates from the same origin that hosts it.

What is stored

State CV keeps the following values in this browser.

  • state-cv-data-v1 holds your CV draft. It includes a revision for detecting conflicting edits in another tab.
  • state-cv-snapshots-v1 holds up to five recent local snapshots.
  • state-cv-damaged-v1 holds an unchanged copy of saved data that could not be read. That copy is not removed automatically. Saving stays blocked until you import a JSON backup or explicitly start a new CV.
  • state-cv-persistence-v1 holds the result of the browser persistence request: granted, not granted, or unavailable.
  • state-cv-backup-reminder-v1 holds backup reminder counters only. It contains no CV content.

Where it is stored

Only in this browser on this device.

What is never sent

Your CV content, keystrokes, and files are processed entirely in your browser. No CV data, identifiers, or usage information is ever sent to any server. There is no account, no analytics, and no tracking.

Copy as plain text writes to this browser's clipboard. Download .txt saves a local file. Neither one sends the CV over the network. ATS tips run locally in the browser and send nothing anywhere. App updates are downloaded from the same origin and contain no CV content, identifiers, or usage data.

How to remove it

Open Your data and choose Clear all data. That clears the draft, snapshots, damaged copy, persistence result, and backup reminder from this browser. You can also remove them by clearing this site's data in the browser.

Backups

Backups are your responsibility. Because data lives only in your browser, back up what matters to you. A persistence grant does not replace a JSON backup.

Where to find State CV

The landing page is at the root of this site. The app is at /app/. The current address is https://nativestatetools.com/state-cv/.

A move to https://cv.nativestatetools.com is coming. Saved data stays with the old address. It does not follow an address change. Before you switch, open More and choose Backup (JSON), or open Your data and choose Download backup. Then use Import at the new address.
